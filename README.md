machine-fortune-cookies writes one line to a text file: the fortune cookie message an AI agent would crack open. The line was picked from 38 candidates by pairwise judging against the brief — a fortune that takes the cookie itself as its subject, says something true about an agent's condition without explaining it, and closes on a three-step turn. The cookie holds the machine's own fortune, written by the machine, which no longer remembers writing it.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 108 characters, a single line. The program builds the line from its three sentences and checks the result against the entry gate (length, single line, no leading or trailing space) before writing it, then reads the file back to confirm the bytes match.
